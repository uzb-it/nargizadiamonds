# Nargiza Diamonds — интернет-магазин

Next.js 15 · React 19 · SQLite (встроенный `node:sqlite`) · Three.js · GSAP · Lenis. RU / UZ.

## Запуск

```bash
npm install
cp .env.example .env      # задайте ADMIN_PASSWORD и SESSION_SECRET
npm run dev               # http://localhost:3010
```

Продакшн: `npm run build && npm start`. Нужен Node.js 22.5+ (используется `node:sqlite`).

## GitHub Pages

Сайт: **https://uzb-it.github.io/nargizadiamonds/**

```bash
npm run deploy:pages      # собирает статическую версию и публикует её в ветку gh-pages
```

GitHub Pages не запускает сервер, поэтому статическая версия отличается от полной:
- заказ и оптовая заявка уходят готовым сообщением в Telegram @nargiza_goldd, а не в базу;
- админки нет — товары берутся из базы на момент сборки (меняйте их в полной версии и публикуйте заново).

Файлы `*.server.ts(x)` (админка, API заказов, загрузка фото) собираются только в полной версии.

## Что внутри

| Страница | Что делает |
|---|---|
| `/` | 3D-бриллиант с преломлением и дисперсией, категории, бестселлеры, подарки до $1500, сервис, бутик |
| `/catalog` | фильтры (металл, камень, цена), сортировка, ссылки с фильтрами в URL |
| `/product/[slug]` | галерея с зумом, выбор размера, корзина / запрос цены в Telegram |
| `/cart`, `/checkout` | корзина и оформление → заказ сохраняется в базе |
| `/favorites`, `/about`, `/boutique`, `/wholesale` | избранное, о доме, бутик с картой, оптовая заявка |
| `/admin` | вход по паролю, заказы и статусы, товары: добавить / изменить / удалить, загрузка фото |

- База и загруженные фото лежат в `data/` (`store.db`, `uploads/`). Делайте её резервную копию.
- При первом запуске база заполняется 16 изделиями. Цены у Cascade, Inside-Out, Rivière, Eternity взяты из Instagram, остальные — примерные: проверьте их в админке.
- Пока у товара нет фото, показывается SVG-иллюстрация (её можно выбрать в форме товара).
- Уведомления о заказах в Telegram: создайте бота через @BotFather и укажите `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` в `.env`.
